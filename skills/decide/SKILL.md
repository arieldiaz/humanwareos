# Decide

Use when the work needs an explicit choice or sequence.

1. State the decision and its reason in one sentence.
2. Check it against current strategy and named constraints.
3. Define the smallest useful tranche, usually three to seven ordered steps.
4. Give each step an observable completion condition and identify any irreversible step.
5. Record the decision as evidence when it should survive the conversation.

Done when one plan can be executed without reopening the same decision. Use the optional challenge skill before a consequential irreversible step when an independent opposing view would materially improve the choice.
