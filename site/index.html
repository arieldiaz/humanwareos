The system

AI should compound your context, not consume your attention.

Humanware OS is a small, opinionated framework for giving durable agents a shared memory, a clear operating loop, and access to the interfaces you already use. It is not another chatbot. It is the layer that helps the human stay oriented.

The loop

A system that learns from living.

  1. 1ObserveCapture what happened.
  2. 2OrientConnect it to context.
  3. 3DecideChoose what matters.
  4. 4ActDo the work.
  5. 5ReviewCompare intent to result.
  6. 6CompoundWrite the lesson back.
Getting started

Start with the agent. Let it build the rest with you.

Configure one durable agent locally, then give it the machine and the guide. It should drive every safe terminal, API, and UI step. You step in for identity, consent, and secrets.
